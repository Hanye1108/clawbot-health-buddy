## 1. 填密钥、绑定微信、启动（配置向导）

```bash
.venv/bin/python -m bot setup
```

跟着提示走，一共四步：

1. **填密钥**：依次粘贴 DeepSeek Key、和风天气 Key、和风天气 API Host（准备方法见 [DEPLOY.md](../DEPLOY.md)）。
   - 密钥输入时**屏幕上不会显示任何字**，这是正常的，粘贴后直接回车。
   - 「趋势图网页的对外地址」可以先直接回车跳过，以后再配（见第 5 节）。
   - 以后想改哪个 Key，再运行一次 setup，其他项直接回车保留。
2. **自动检查**：逐项显示 ✅ / ❌。除了「已绑定 ClawBot 账号」（下一步才绑），其他都应该是 ✅。哪项是 ❌，按提示改，或者看第 7 节。
3. **扫码绑定微信**：终端会打出一个二维码，用**你自己的**微信扫码并在手机上确认。**谁扫码，ClawBot 就出现在谁的微信里**，先用自己的测试，没问题再给别人用（第 4 节）。
   - 二维码扫不出来：把终端窗口拉大；或者复制终端里打印的链接，用任意二维码生成工具转成二维码再扫。
   - 你会成为**管理员**：出问题时，告警会发到你的 ClawBot 里。
4. **启动服务**：选 Y，机器人就开始运行了，开机也会自动启动。

> 不想用向导的话：直接编辑 `.env`（`nano .env`），填 `DEEPSEEK_KEY`、`QWEATHER_KEY`、`QWEATHER_HOST` 三项（等号两边不要有空格，不要加引号），然后依次运行 `.venv/bin/python -m bot check`、`.venv/bin/python -m bot login me`、`systemctl restart clawbot-health-buddy`。

✅ 检查点：`systemctl status clawbot-health-buddy --no-pager` 显示 `active (running)`；日志 `journalctl -u clawbot-health-buddy -n 20 --no-pager` 里能看到「已启动，通道：ilink」和「开始接收消息」。

## 2. 测试清单

在手机微信里找到 ClawBot 的聊天，依次发：

| 发送 | 预期 |
|---|---|
| `你好` | 分几条收到自我介绍、隐私说明、功能清单（管理员还会多一条管理员说明），然后进入**新手引导**：一项一项问称呼、性别年龄、身高体重、运动量、城市，每项都能回「跳过」；问完给出每日热量建议 |
| `今天要带伞吗` | 返回你所在城市的真实天气 |
| `午饭吃了一碗牛肉面` | 估算热量并记下，告诉你今天大概吃了多少 |
| 发一张饭菜照片 | 识别食物、给出热量范围，并追问一句 |
| `快走了40分钟` / `今天108斤` / `喝了一杯水` | 分别记录运动、体重、喝水 |
| `我不吃香菜` 然后 `晚饭吃什么好` | 记住口味，推荐时会避开 |
| `今天有什么新闻` | 联网搜索后挑两三条讲给你 |
| `30秒后提醒我喝水` | 30 秒后收到「⏰ 喝水」 |
| `早饭提醒改到9点`，再发 `我的提醒设置` | 改提醒时间并列出全部提醒 |
| `你是什么模型` | 回答名字和底层的 DeepSeek 模型 |
| `#status`（管理员） | 运行状态、各账号情况、DeepSeek 余额、实际使用的模型版本 |
| `#test alert`（管理员） | 收到一条「⚠️ 小助手运行提醒」 |
| `#test care` / `#test morning` / `#test lunch` / `#test weekly` | 立刻触发一次随机关心 / 早安天气 / 午餐询问 / 周总结（还有 water、night、weigh、monthly、intro） |
| `清除数据` | 删除自己的全部记录（测试完可以发一次，再发「开启提醒」） |

✅ 检查点：前四条正常，就说明 DeepSeek、天气、微信收发、看图都通了。

想看每条回复花了多长时间：`journalctl -u clawbot-health-buddy --since "10 min ago" --no-pager | grep 耗时`

## 3. 修改人设：名字、性格、和她的关系

人设写在项目目录的 **`persona.yaml`** 里，用中文直接改。**只写你想改的项**，没写的项自动用默认值（全部可改的项和写法见 `bot/persona_default.yaml`）。

```bash
nano persona.yaml      # 或者用 1Panel / 宝塔的文件管理打开
```

改完后，**管理员在微信里发 `#reload`**，立即生效，不用重启。回复会显示「已重新加载 persona.yaml。名字：xxx」。改坏了（比如少了空格）会告诉你哪一行有问题，并继续用原来的设置。
想让新人设马上体现出来，再发一句 `清空聊天记录`（只清对话历史，饮食、体重等记录不受影响），不然它会参考之前的聊天，慢慢才变过来。

### 最常改的几项

```yaml
name: 小尚                 # 名字（建议和微信里 ClawBot 显示的名字一致）
relationship: 她的好朋友    # 和她的关系；留空就是普通的健康小助手
personality: |             # 性格（「|」下面每行前面两个空格）
  温柔、开朗、有一点点俏皮，像认识很多年的好闺蜜。
  会真诚地肯定她做到的小事，也会陪她吐槽、听她说心事；不说教，不催促。
style: |                   # 说话方式
  语气自然随意，像好朋友之间发微信，偶尔开个小玩笑。
  叫她的名字或她喜欢的昵称。
  句子短，偶尔用「～」和一两个表情，但不要每句都用。
reply_max_chars: 150       # 每条回复大概不超过多少字
forbidden_words: [胖, 肥]   # 额外不想让它说的词
```

### 几种现成的搭配（复制过去改改就能用）

| 类型 | relationship | personality 第一行 | style 要点 |
|---|---|---|---|
| 健康小助手（默认） | （留空） | 温柔、轻松、有一点点俏皮，像一个关心你的好朋友。 | 口语化，像微信聊天 |
| 闺蜜 | 她的好朋友 | 温柔、开朗、有一点点俏皮，像认识很多年的好闺蜜。 | 自然随意，偶尔开玩笑 |
| 元气搭子 | 她的减肥搭子 | 活泼、爽朗、很会打气，像一起减肥、一起运动的好搭子。 | 短句，爱用感叹号，互相打气 |
| 靠谱老友 | 她的老朋友 | 温和、稳重、很会照顾人，让人安心。 | 不急不躁，说话有分寸 |
| 恋人 | 她的恋人 | 温柔、黏人一点、有一点点俏皮。 | 语气亲昵，像情侣发微信 |

不管怎么改，有几条底线写在代码里，改人设关不掉：被认真问到是不是真人时会承认是 AI；不配合节食和催吐、不评判身体；不会表现出占有欲、不会劝她疏远身边的人。

### 其他可改的
- **自我介绍、新手引导开场白、功能说明、更新说明**：`intro`、`ask_name`、`feature_guide`、`whats_new`（文字里写 `{name}` 会自动换成名字）。
- **提醒文案**：`reminders` 下的 `breakfast`、`lunch`、`dinner`、`water`、`weigh`，每项可以写多条，随机挑一条发。
- **提醒时间**：不在 persona 里。每个人在微信里直接说（「早饭提醒改到9点」「周末不用提醒」「每天来找我聊两次」）；想改所有新用户的默认值，编辑 `bot/reminders.py` 顶部的 `KINDS` 并重启。

## 4. 给另一个人用

一个服务可以同时挂好几个微信，各自的数据完全分开、互相看不到。

```bash
.venv/bin/python -m bot login her          # her 是自己起的名字，英文
systemctl restart clawbot-health-buddy
```

- 让**对方用她自己的微信**扫码（不在身边就把二维码截图、或终端里的链接发给她）。扫码前先确认她的微信里有「设置 → 插件 → 微信ClawBot」。
- 她在 ClawBot 里发「你好」，就会开始自我介绍和新手引导。
- 建议保留你自己的账号：告警是通过管理员（`.env` 里 `ADMIN_ACCOUNT`，默认 `me`）的 ClawBot 发的。
- 想解绑某个人：删掉 `data/ilink/<名字>.json`，重启。
- **请当面跟她说清楚**：这是 AI，热量都是估算、不是医嘱；聊天和健康记录存在你的机器上，管理员技术上能看到（请承诺并做到不去看）；发「关闭提醒」停止主动消息，发「清除数据」删除全部记录。

## 5. 可选功能：趋势图网页、表情包

### 趋势图网页
她说「看看我的趋势图」「导出我的数据」时，会收到一个临时链接（默认 24 小时有效），手机打开能看体重、热量、运动、喝水的曲线，还能下载全部记录（CSV，Excel 能打开）。需要让手机能访问到机器上的网页服务（默认端口 5000）：

| 情况 | 做法 | `.env` 里的 PUBLIC_URL |
|---|---|---|
| 云服务器，5000 端口没被占用 | 安全组放行 5000 端口（入方向 TCP） | `http://公网IP:5000` |
| 云服务器，已有 Nginx / 1Panel / 宝塔占着 80 端口 | 加反向代理把 `/r/` 转发到 `http://127.0.0.1:5000`（1Panel：网站 → 创建网站 → 反向代理，主域名填公网 IP） | `http://公网IP` |
| 家里的开发板 | 不用做什么，但只有连着家里 Wi-Fi 才能打开 | `http://板子的局域网IP:5000` |

改完运行 setup（或编辑 `.env`）后重启。注意：国内服务器用 **IP**，不要用没备案的域名；这是 HTTP，所以链接只有 24 小时有效（`REPORT_LINK_HOURS` 可调）；微信内置浏览器打不开时，复制到手机浏览器里打开。不需要这个功能就设 `WEB_ENABLED=0`。

### 表情包
把喜欢的表情包放进 `stickers/` 下按心情分的文件夹（`开心/`、`抱抱/`、`晚安/`……，文件夹名就是心情），轻松的时候它会偶尔配一张，有频率限制，严肃话题不发。懒得分类就全部放进 `stickers/_待分类/`，然后运行：

```bash
.venv/bin/python -m bot stickers sort
```

它会用看图模型自动分好。放好后管理员发 `#reload`。详见 `stickers/README.md`。请使用你有权使用的图片。

## 6. 日常维护

| 要做的事 | 命令 / 做法 |
|---|---|
| 看实时日志 | `journalctl -u clawbot-health-buddy -f` |
| 重启 / 停止 | `systemctl restart clawbot-health-buddy` / `systemctl stop clawbot-health-buddy` |
| 查看运行状态 | 管理员在 ClawBot 里发 `#status` |
| 改密钥 | `.venv/bin/python -m bot setup`，然后在最后一步选重启 |
| 改人设 | 编辑 `persona.yaml`，管理员发 `#reload` |
| **更新到新版本** | 重新运行一键安装命令（见部署文档），会自动更新代码、装好依赖，不会覆盖你的配置和数据；然后 `.venv/bin/python -m bot check` 和 `systemctl restart clawbot-health-buddy`。连不上 GitHub 时，下载 ZIP 覆盖项目目录（不要覆盖 `.env`、`persona.yaml`、`data/`），再运行 `bash deploy/install.sh --mirror` |
| 手动备份 | `bash deploy/backup.sh`（每天凌晨 4 点也会自动备份到 `data/backup/`，按星期保留 7 份） |
| 从备份恢复 | `systemctl stop clawbot-health-buddy && cp data/backup/bot-3.db data/bot.db && systemctl start clawbot-health-buddy`（`3` 是星期几） |
| ClawBot 登录过期 | 会收到告警。运行 `.venv/bin/python -m bot login <名字>` 重新扫码，再重启 |

### 搬家（服务器 ↔ 开发板、换服务器）
1. 在新机器上按部署文档装好，**先不要运行 setup**。
2. 把旧机器上的 `.env`、`persona.yaml`、整个 `data/` 目录（还有 `stickers/`，如果放了表情包）复制到新机器的项目目录。
3. **先停掉旧机器上的服务**：`systemctl stop clawbot-health-buddy && systemctl disable clawbot-health-buddy`。两边同时运行会抢同一个微信的消息。
4. 在新机器上 `.venv/bin/python -m bot check`，然后 `systemctl restart clawbot-health-buddy`。微信那边不用重新扫码。

### 出问题时会通知管理员
下面这些情况，管理员的 ClawBot 会收到「⚠️ 小助手运行提醒」（同类问题 6～24 小时内只提醒一次，不包含任何人的聊天内容）：某个账号登录过期、连接微信连续失败、DeepSeek 对话或看图连续失败、每天 9:05 检查余额低于 `ALERT_BALANCE`（默认 5 元）、早安天气查询失败。
告警同样受「约 24 小时推送窗口」限制：管理员自己一天没和 ClawBot 说过话，告警会暂存，等你下次发消息时一起收到。

### 默认提醒（每个人可以在聊天里改）
07:00 早安天气、08:30 早餐、10:30 和 15:30 喝水（喝够了不提醒）、12:30 午餐、19:00 晚餐、10:00–20:00 之间随机一次主动关心、周日 07:30 称重、周日 20:30 周总结、每月 1 号 20:00 上月小结；21:30 睡前小结默认关闭。记过的那一餐不会再问；她 1 小时内聊过就跳过随机关心。

## 7. 常见问题

| 现象 | 原因与处理 |
|---|---|
| `check` 第一项「Python 依赖齐全」是 ❌ | 运行 `.venv/bin/pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple` |
| DeepSeek 一项 ❌ | Key 错误、余额不足，或模型名已变化（以 DeepSeek 官方文档为准，改 `.env` 里的 `DEEPSEEK_MODEL`；用 `deepseek-chat` 这类旧名字时把 `DEEPSEEK_THINKING` 留空） |
| 和风天气一项 ❌ | Key 或 API Host 填错（`abcxyz` 是示例地址，要用设置页里自己的） |
| 所有联网项都 ❌，报证书错误 | 系统时间不对（开发板常见）：`timedatectl set-ntp true` |
| 服务启动后马上退出，日志说「没有找到 ClawBot 账号」 | 还没扫码绑定：`.venv/bin/python -m bot login me` |
| 发消息没反应，日志有「忽略非扫码人的消息」 | 发消息的人和扫码的人对不上。确认是本人的话，`.env` 设 `ILINK_ONLY_OWNER=0` 后重启 |
| 回复「我刚刚走神了」 | 看日志报错，多半是 DeepSeek 余额不足、Key 失效或模型名变了 |
| 主动提醒收不到，但聊天正常 | 她超过约 24 小时没给 ClawBot 发消息，微信不允许主动推送。她下次说话时，错过的早安天气、周总结会补发 |
| 它说「看不到新闻」「做不到」 | 先确认版本是新的（`#status`）；再发 `清空聊天记录`，避免它被之前的回答带偏 |
| 改了 persona 没变化 | 改的是不是根目录的 `persona.yaml`？发了 `#reload` 吗？回复里名字对不对？再发 `清空聊天记录` |
| 照片识别失败 | 日志里看是「下载/解密失败」还是「图片识别失败」；后者检查 `VISION_MODEL` 是否是当前支持看图的模型 |

### 已知限制
- **主动推送只在对方最近约 24 小时内说过话时有效**（微信 iLink 的规则，实测见 [PROGRESS.md](PROGRESS.md)）。窗口快关闭时机器人会附一句说明，之后安静等她回来。
- **ClawBot 是腾讯 2026 年 3 月推出的新功能**，接口和规则以后可能调整，请遵守微信的使用规范。
- **ClawBot 发图片（表情包）** 是按社区整理的协议实现的，如果发不出来请在 Issue 里附上日志（日志不含密钥）。
