# 备选通道：微信公众号测试号

如果你的微信还没有「ClawBot」插件，可以先用公众号测试号。功能完全一样，区别是：

| | 微信 ClawBot（推荐） | 公众号测试号 |
|---|---|---|
| 在微信里的样子 | 一个普通聊天，可以置顶 | 一个公众号，不能置顶，顶部可能有系统提示 |
| 服务器要求 | 只要能上网 | 微信要能从公网访问你服务器的 **80 端口** |
| 主动推送 | 依赖会话令牌 | 用户 48 小时内发过消息才能发客服消息，否则用模板消息兜底 |

## 1. 申请测试号

搜索「微信公众平台 接口测试帐号申请」，进入官方页面，用微信扫码登录，记下 **appID** 和 **appsecret**。

## 2. 配置 `.env`

```ini
CHANNEL=mp
WX_TOKEN=自己随便定一串字母数字
WX_APPID=测试号的appID
WX_APPSECRET=测试号的appsecret
MP_PORT=5000
```

## 3. 让微信能访问到服务

程序监听 `MP_PORT`（默认 5000），路径是 `/wx`。微信只能访问 80/443 端口，所以：

- **80 端口空闲**：把 `MP_PORT` 改成 `80`。
- **80 端口已被 Nginx/OpenResty 占用**（比如装了宝塔、1Panel）：加一个反向代理，把 `/wx` 转给 `http://127.0.0.1:5000`。Nginx 写法：

  ```nginx
  location /wx {
      proxy_pass http://127.0.0.1:5000;
      proxy_set_header Host $host;
      proxy_set_header X-Real-IP $remote_addr;
  }
  ```

  1Panel：网站 → 创建网站 → 反向代理，主域名填服务器公网 IP，代理地址填 `http://127.0.0.1:5000`。

- **国内服务器 + 未备案域名**：80/443 会被云厂商拦截，直接用服务器的**公网 IP**，不要用域名。

验证：`curl -i http://你的公网IP/wx` 返回 `403 forbidden` 说明转发成功（没带微信签名被拒绝是正常的）。

## 4. 在测试号页面填写接口配置

- URL：`http://你的公网IP/wx`
- Token：和 `.env` 里的 `WX_TOKEN` 一致

先 `systemctl start clawbot-health-buddy`，再点提交，显示配置成功后扫码关注测试号。

## 5. 模板消息（可选，用于兜底推送）

测试号页面 →「模板消息接口」→ 新增测试模板：标题 `小助手提醒`，内容 `{{content.DATA}}`。把得到的模板 ID 填到 `.env` 的 `WX_TEMPLATE_ID`，重启服务。

用户超过 48 小时没说话时，早安天气、周总结会改发一条短的模板消息提醒她回复，她回复后自动补发全文。
