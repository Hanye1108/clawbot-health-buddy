# 表情包

把表情包图片放在这里，**按心情分子文件夹**，文件夹名就是心情（中文也可以）：

```
stickers/
  开心/    xxx.gif  yyy.png
  抱抱/
  夸夸/
  加油/
  早安/
  晚安/
  撒娇/
  喝水/
  吃饭/
```

- 支持 png、jpg、gif、webp，单张不超过 2MB。
- 心情可以随便加，建了文件夹、放进图片就会生效；空文件夹会被忽略。
- 加完后管理员在微信里发 `#reload`（或重启服务），回复里会列出识别到的心情。
- AI 会根据聊天氛围挑心情、从文件夹里随机选一张，在文字回复后面发出去；
  每隔几条回复最多一张、每天有上限，严肃或难过的话题不会发。
- 这个文件夹里的图片不会提交到 Git。请使用你有权使用的图片。
