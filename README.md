# clawbot-health-buddy · 微信 AI 健康小助手

一个住在微信里的 AI 健康小助手：陪聊天、记录饮食/运动/体重、按时提醒喝水和吃饭、每天早上报天气、每周写一份温和的小结。由 DeepSeek 驱动，部署在你自己的服务器或家里的 ARM 开发板上。

最初是给女朋友做的个人项目：希望它像一个贴心的朋友，而不是一个让人焦虑的计数器。

## 功能

- 💬 **聊天**：日常闲聊，记得之前聊过什么（对话历史存在本地 SQLite）
- 🍜 **饮食记录**：说一句「午饭吃了牛肉面」或**拍张照片**，估算热量并记下，随时告诉你今天大概吃了多少
- 🏃 **运动记录**：「快走 40 分钟」按 MET 公式估算消耗；手表数字也可以直接报
- ⚖️ **体重记录**：只看趋势，不盯单次；减得太快会温和提醒放慢
- 🎯 **热量目标**：用 Mifflin-St Jeor 公式在代码里计算，带安全下限，大模型只负责讲解
- 💧 **喝水记录**：「喝了一杯水」；喝水提醒会说今天喝了多少，喝够了就不再提醒
- 😋 **口味与忌口**：「我不吃香菜」「乳糖不耐」会被记住，问「晚饭吃什么」时结合剩余热量和口味推荐
- 🌤 **天气**：随时问；每天 7 点主动推送天气和穿衣建议
- 🐱 **表情包**：把自己喜欢的表情包按心情放进 `stickers/开心/`、`stickers/晚安/` 等文件夹，轻松的时候会偶尔配一张（有频率限制，严肃话题不发）
- 🔎 **联网搜索**：问新闻、最近的事、价格等实时信息时自动搜索（DeepSeek 官方 Search API，同一个 Key）
- 💬 **随机关心**：白天在随机时间主动发一句关心或问候，结合当天情况和之前聊过的事现写，不重复；她刚聊过就不打扰，次数和时间段可调
- ⏲ **临时提醒**：「20 分钟后提醒我喝水」「下午 3 点提醒我开会」「每天晚上 9 点提醒我吃维生素」，可查看、取消，服务重启不丢
- ⏰ **个性化提醒**：每个人一套设置，直接说「早饭提醒改到 9 点」「周末不用提醒」「开启睡前小结」；记过的那餐不再问
- 📊 **周总结、月度小结**：统计由代码完成，大模型写成一段有温度的话；数据不足时坦白说看不出结论
- 📈 **趋势图与导出**：「看看我的趋势图」会发一个临时链接（默认 24 小时有效），手机上看体重、热量、运动、喝水曲线，还能下载 CSV
- 👋 **首次自我介绍与新手引导**：第一次聊天时介绍自己、隐私说明和全部功能，再一项一项问称呼、性别年龄、身高体重、运动量和城市（都能跳过），问完直接给出每日热量建议；发「功能介绍」「重新填写资料」随时再来
- 🎙 **语音**：ClawBot 通道下语音消息自动转文字

## 自定义名字和性格

助手默认叫「小禾」。名字、性格、说话方式、自我介绍、提醒文案都在 `persona.yaml` 里，用中文直接改，管理员在微信里发 `#reload` 立即生效：

```yaml
name: 阿暖
personality: |
  元气满满，像一个爱运动的闺蜜。
reply_max_chars: 120
```

安全相关的规则写在代码里，改人设不会关掉它们。

## 安全与隐私设计

健康和体重是很私密、也很容易让人焦虑的话题，这个项目把下面几条写进了代码和提示词：

- 不配合极端节食、断食、催吐、过度运动；遇到怀孕、慢性病、未成年、吃完就自责等情况，不给减重数字，建议找医生、营养师或身边信任的人。
- 每日摄入有安全下限；未满 18 岁或 BMI 偏低时只给维持量，不设减重缺口。
- 不评判身体和饮食，不夸"吃得少""减得快"。
- 首次对话说明自己是 AI、数据存在哪里；「清除数据」一键删除全部记录。
- 所有数据只存在你自己服务器的 SQLite 文件里。

> ⚠️ 本项目给出的热量、消耗都是**估算**，不是医疗建议。

## 架构

```
 微信（她的手机）
     │  ClawBot 聊天 / 公众号测试号
     ▼
 微信服务器 ──(iLink 长轮询，服务器主动连接，无需公网端口)──┐
                                                       ▼
                         ┌──────── 你的服务器 ─────────────────────┐
                         │ bot/channels   收发消息（ilink / mp）    │
                         │ bot/core       处理消息、定时推送        │
                         │ bot/tools      给模型用的工具            │──► DeepSeek（对话、看图）
                         │ bot/records    记录与计算（SQLite）      │──► 和风天气
                         └─────────────────────────────────────────┘
```

两种微信通道：

| 通道 | 说明 |
|---|---|
| `ilink`（推荐） | 微信 2026 年 3 月开放的官方个人号机器人协议（ClawBot 插件）。扫码绑定后，ClawBot 作为一个普通聊天出现在微信里，可以置顶。**不需要域名、备案和公网端口。** |
| `mp` | 公众号测试号，需要微信能访问你服务器的 80 端口。见 [docs/MP_TEST_ACCOUNT.md](docs/MP_TEST_ACCOUNT.md)。 |

## 快速开始

两种部署方式，**服务器**或**百元级 ARM 开发板**（放在家里，不需要公网 IP），都是一条命令安装：

```bash
curl -fsSL https://raw.githubusercontent.com/Hanye1108/clawbot-health-buddy/main/deploy/bootstrap.sh | sudo bash -s -- --mirror
cd /opt/clawbot-health-buddy && sudo .venv/bin/python -m bot setup   # 填密钥 → 自检 → 扫码绑定微信 → 启动
```

## 在微信里怎么用

直接说话就行：「午饭吃了一碗牛肉面」「今天 108 斤」「跑步 30 分钟」「这周总结」「明天要带伞吗」，或者拍一张饭菜照片。

内置指令：`关闭提醒` `开启提醒` `关闭称重提醒` `开启称重提醒` `清除数据` `帮助`
管理员指令：`#status` 查看运行状态和 DeepSeek 余额，`#reload` 修改 persona.yaml 后立即生效，`#test alert` 测试告警（出问题时会自动通知管理员，见 [docs/after-deploy.md](docs/after-deploy.md)）
测试指令（立即触发一次推送）：`#test morning|breakfast|lunch|dinner|water|weigh|weekly`

## 项目结构

```
bot/
  __main__.py      命令行：run / setup / check / login / accounts / stickers
  setup_wizard.py  配置向导：填密钥、自检、扫码绑定、启动
  config.py        读取 .env
  db.py            SQLite
  records.py       资料、热量计算、饮食/运动/体重记录与统计
  tools.py         提供给模型的工具定义
  llm.py           DeepSeek 调用（对话、写作、看图）
  core.py          消息处理、自我介绍、主动推送、告警
  reminders.py     每人一套提醒设置与调度（改默认提醒时间看这里）
  onboarding.py    新手引导：逐项收集基本资料
  timers.py        临时提醒（几秒到 30 天后，可每天重复）
  web.py           趋势图网页与 CSV 导出
  persona.py       读取人设配置（名字、性格、问候语、提醒文案）
  persona_default.yaml  人设默认值；复制到根目录 persona.yaml 修改，#reload 生效
  prompts.py       功能规则与安全规则（一般不用改）
  weather.py       和风天气
  search.py        联网搜索（DeepSeek Search API）
  stickers.py      表情包（读取 stickers/ 文件夹）
  channels/
    ilink.py       微信 ClawBot 通道
    mp.py          公众号测试号通道
deploy/            一键安装（bootstrap.sh 下载 + install.sh 安装，自动适配 ARM）、systemd 服务、备份脚本
docs/              部署文档（服务器 / ARM / 部署之后）、进展记录、测试号通道说明
tests/             单元测试（python -m unittest，无需联网）
```

## 开发与测试

```bash
PYTHONPATH=.:tests python -m unittest discover -s tests
```

测试不访问任何外部服务。

## 进展与已知问题

见 [docs/PROGRESS.md](docs/PROGRESS.md)。ClawBot 通道的聊天、天气、拍照识别都已在真实微信里验证，文字回复约 2～3 秒。

> ClawBot 的主动推送只在对方最近约 24 小时内说过话时有效（已实测）。对方一天没理机器人，它就安静下来，等对方回来再补发错过的天气和周总结。
